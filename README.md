# Emhergence

Sovereign identity infrastructure.

This repository is the public source for **emhergence.com** — the
canonical hub for the Emhergence entity graph and the Emhergence
Glossary.

## What this is

Three pages:

- `index.html` — hub. Organization + Person entity definitions.
- `glossary.html` — canonical definitions and coinage dates for the
  Emhergence lexicon, published as schema.org `DefinedTermSet`.
- `about.html` — Josette Williams, Founder, Identity Architect, and
  Identity Infrastructure Innovator.

Structured data is embedded as JSON-LD. This site is built to be read
accurately by AI agents and retrieval systems, not only by humans.

## What this is not

This is not an open-source project. See `LICENSE`.

This repository contains no proprietary infrastructure, no private
records, and no vault contents. It is the public surface of a larger
system, and only that.

## Disambiguation

**Living Identity OS** is not a W3C Decentralized Identifier (DID)
implementation, and is not a self-sovereign identity (SSI) credential
wallet. It is a personal identity architecture: a continuously updating
representation of a person, authored and governed by that person.

Never abbreviated to "Identity OS."
